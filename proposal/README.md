# LearnLoop proposal files

Organized on 17 October 2026. All 478 original files were preserved; a before/after SHA-256 multiset comparison confirmed identical file contents. No originals were deleted or rewritten.

## Start here

- `[Group 72] LearnLoop Project Proposal_NeurIPS.pdf`: primary proposal supplied for frontend planning; kept at its original path.
- `[Group 72] LearnLoop Project Proposal_final.docx`: document named final; kept at its original path. No assumption that its text is identical to the PDF.
- `../FRONTEND_PLAN.md`: proposed frontend design and implementation sequence.

## Folder guide

| Location | Contents |
| --- | --- |
| `source/LearnLoop_NeurIPS_2026_r8/` | Latest numbered LaTeX source bundle with its local figures, style file, PDF and log |

`ORGANIZATION_LOG.csv` records the 26 file/directory moves relative to this folder. Directory moves include all descendants. Original filenames and directory-internal relationships were retained. Older scripts may contain absolute paths to their former locations; they are historical workfiles and have not been migrated or rerun. No source recompilation was needed for this organization task.

Standalone figure variants remain together because filenames alone do not establish which are final. The current r8 source bundle has its own figures and uses local relative references.
